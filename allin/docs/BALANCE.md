# ALL IN 밸런스 · 연출 설계 (2026-11-19)

숫자는 전부 `index.html` 맨 위쪽 `BAL` 표에 모았다. 바꿀 때는 여기 목표를 보고, `node tools/sim.mjs 200` 으로 봇을 돌려 확인한다.

## 1. 참고한 게임과 가져온 원칙

| 게임 | 가져온 것 |
|---|---|
| 슬레이 더 스파이어 | 체력이 등반 전체의 자원이다. 일반 전투는 조금씩 깎고(최대 체력의 약 10%), 엘리트는 아프지만 보상이 일반의 2.5~3배, 보스는 크게 아프다. 회복은 귀하게(휴식 30%). 개발사는 카드마다 고른 비율 · 이긴 비율을 모아 숫자를 맞췄다 — 우리 봇 검사가 그 역할. |
| 발라트로 | 드문 족보일수록 훨씬 세다(원페어 10×2 → 투페어 20×2 → 트리플 30×3 → 스트레이트 30×4 → 플러시 35×4 → 풀하우스 40×4 → 포카드 60×7). 무엇이 점수가 됐는지 카드를 들썩이며 보여 준다. 보스 문턱은 작은 문턱의 2배. |
| 하스스톤 전장 | 계속 커지는(눈덩이) 유닛은 '초반 속도'를 깎아 맞춘다. 우리 쫄병이 2라운드만 싸우는 규칙과 같은 방향. |
| 타격감 자료 | 예비 동작(뒤로 살짝) → 타격 → 맞는 순간 2~5프레임 멈춤(히트스톱, 양쪽 다) → 밀림. 화면 흔들림 · 섬광은 큰 사건에만. 선형 움직임 금지(가속 · 감속). |

### 족보 사다리 확인
쫄병 싸움은 '수 × 공격'과 '수 × 체력'이 둘 다 커져서, 세기는 대략 (쫄병 수 × 배율)² 로 오른다. 지금 표를 이 식으로 바꾸면 원페어 4 · 투페어 9 · 트리플 18 · 스트레이트 23 · 플러시 41 · 풀하우스 64 · 포카드 144. 발라트로의 비율(원페어:투페어:트리플 = 1 : 2 : 4.5)과 거의 같아서 족보 표는 **그대로 둔다**.

봇은 '꽤 하는 사람' 수준으로 친다 — 승률 계산으로 콜 · 레이즈 · 폴드, 페어 · 같은 무늬를 골라 든다.

| 항목 | 목표 | 근거 |
|---|---|---|
| 등반 성공률 | 25~40% | 슬더스 기본 난이도 실제 승률 9~16%보다 조금 높게(봇은 실수가 적은 대신 칩 · 유물 조합을 못 짠다) |
| 일반 전투 체력 손해 | 최대 체력의 8~14% | 슬더스 일반 전투 |

| 전투 길이 | 일반 3~5 · 엘리트 4~6 · 보스 6~9 라운드 | 한 판이 너무 길다는 지적(2026-11-17) |

## 3. 지금 숫자 측정 (봇 200판, 수정 전)

- 등반 성공 **0.5%** (200판 중 1판)
- 1층 일반 전투 하나에 **체력 27.8 손해 (31%)**, 일반 전투에서 죽는 비율 18%
- 1층 엘리트 33.4 손해 · 죽는 비율 39%, 1층 보스 39.5 손해 · 48%
- 라운드당 내 본체가 맞는 양 8.1, 적 본체에 주는 양 11.9, 쇼다운 이기는 비율 55%
- 아무도 안 맞는 라운드 2% → 문제 아님 (판돈을 본체에서 빼는 규칙은 넣지 않음)
- 원인: 일반 적의 쫄병이 나와 같은 세기라, '조금 유리한 싸움'을 6라운드 하면서 매번 비슷하게 맞는다.

## 5. 연출 (타격감)

| 장면 | 이렇게 |
|---|---|
| 근접 공격 | 뒤로 10px 당김(예비 동작) → 앞으로 찌름 → 맞는 순간 멈칫 → 돌아옴 (0.38초). 피해는 '맞는 순간'에 들어간다 |
| 원거리 · 회복 | 기 모으기(빛나며 부풂) → 탄이 날아감 → 터짐 |
| 맞음 | 하얗게 번쩍인 채 잠깐 멈춤(히트스톱) → 맞은 방향으로 밀림 · 기울어짐 → 제자리. 세게 맞을수록 많이 밀린다 |
| 숫자 | 전장 위에 크게 튀어나왔다가 떠오르며 사라짐. 체력 대비 큰 피해일수록 크게, 치명타는 노랑 + '치명!' |
| 쓰러짐 | 번쩍 → 살짝 튀었다가 기울며 가라앉음 + 카드 조각 6개가 흩어짐 |
| 빈자리 | 남은 쫄병이 빈자리로 미끄러져 감 (순간이동 X) |
| 소환 | 한 명씩 차례로 떨어져 찌그러졌다 펴짐 |
| 돌격(본체 공격) | 남은 쫄병마다 빛줄기가 상대 체력바로 꽂힘 → 체력바 흔들림 + 큰 숫자. 최대 체력의 15% 넘게 맞을 때만 화면 흔들림, 내가 맞으면 붉게 번짐 |
| 카드 | 공용 카드는 뒤집히며 깔림, 쇼다운에 적 손패가 뒤집힘. 족보에 쓰인 카드는 금빛으로 들썩, 안 쓰인 카드는 흐리게 |

- 싸우는 동안 전장을 통째로 다시 그리던 것을 없앴다. 예전엔 쫄병 하나가 움직일 때마다 전장 전체를 새로 그려서 다른 쫄병의 움직임이 중간에 끊겼다.
- 2배속 · '움직임 줄이기' 설정을 따른다. 데모 전투 한 번: 수정 전 5.3초 → 4.2초 (연출이 늘었는데 기다리는 시간을 줄여서 더 빠름).

## 6. 고친 버그
- 저주 카드 두 장만 손에 들면 족보 판정이 멈춰 전투 화면이 굳었다 (봇이 찾음). 빈 손은 하이카드 0으로 친다.

## 7. 바카라 섞기 (2026-11-19)

**규칙:** 손패 두 장을 홀덤 족보로도, 바카라로도 읽는다. 바카라 점수 = 두 장 합의 끝자리 (A=1, 10 · J · Q · K = 0, 저주 = 0, 조커 = 9가 되게).
- 홀덤 족보 → 쫄병 수 · 세기 (그대로)
- 바카라 → 기세: 점수 높은 쪽 쫄병이 매 턴 먼저 움직인다
- 내추럴 9 → 상대 본체에 판돈 ×1, 8 → 판돈 ×0.5 (적도 똑같이)
- 타이(같은 점수) → 그 라운드 판돈 두 배
- 왜: 발라트로처럼 같은 카드를 두 가지로 읽게 해서, 3장 중 2장을 고르는 순간 '페어(족보)냐 9(바카라)냐' 고민이 생긴다.

**봇 측정 (120판):**
| | 바카라 전 | 내추럴 ×2/×1 | **내추럴 ×1/×0.5 + 일반 · 엘리트 적 0.5 · 0.6** |
|---|---|---|---|
| 등반 성공률 | 12% | 5% | **16.7%** |
| 일반 전투 체력 손해 | 8~10 | 10~15 | **6~9.5** |
| 라운드당 내추럴 피해 (적에게 · 나에게) | – | 2.9 · 1.5 | 1.4 · 0.8 |

- 내추럴을 세게 하면 오히려 어려워졌다: 내 내추럴은 전투를 조금 줄일 뿐인데, 적 내추럴은 30번 넘는 전투 내내 내 체력을 깎아 쌓인다.
- 남은 벽: 2층 사장(카지노 지배인)에서 31%가 죽는다. 너무 높으면 `rig` 를 .15 로.
