# ALL IN 올인 던전 — 작업 메모 (클라우드 세션용)

- 원본은 사용자 PC 의 프로젝트(src/eval.js · src/data.js · src/game.js, docs/art, tools/make_art.py)를 한 장으로 묶은 아티팩트다.
  https://claude.ai/artifact/5iWLToD2ESWbpMTfgjraqD (2026-11-18 13:21 KST 버전)
- 여기 `index.html` 은 그 사본이다. 밖에서 작업한 뒤 나중에 PC 프로젝트에 **덮어쓴다**(사용자 결정).
- PC 1920×1080 가로 무대, 창에 맞춰 비율 확대·축소. 포커 족보로 쫄병을 소환하는 로그라이크(문 고르기 → 전투 → 보상).
- 시안 그림이 base64 로 들어 있어 줄 몇 개가 40만 자다. 통째로 읽지 말고 필요한 줄만.

## 사용자에 대해 (jihun4179/dev 의 CLAUDE.md 들에서 모음)

- **코드를 직접 읽지 못한다.** 설명은 코드 말고 말로, 원리를 풀어서. 무엇을 왜 바꿨는지 한국어로 짧게
- 중간 확인 묻지 말고 끝까지 진행한 뒤 검증 결과와 함께 보고. **두 번 일하는 걸 싫어한다 — 한 번에 제대로**
- 에러는 원인과 해결책을 말로 먼저 정리
- 파일을 많이 쪼개지 말 것(어디 뭐가 있는지 추적이 어렵다)
- 받은 지적들(다른 게임에서):
  - 글자·버튼 겹침 금지
  - 탭은 지금 어디인지 직관적으로(금 테두리+빛)
  - "임의로 만든 티" 나는 미리보기 금지 — 진짜 스크린샷
  - 화면 전체 섬광·흔들림은 큰 사건에만
  - 도형 UI 도 일관성(재질 하나·색 몇 개·장식 규칙 하나)이 있으면 조잡하지 않다
  - 조잡해 보이는 건 빼거나 보류(결과 화면 증강 목록 숨김, 증강 36장 보류 사례)
  - 버튼 규격은 몇 가지로 통일
- 입력칸: 키패드 바로 위 한가운데, 글자 크게. 화면에 들어서자마자 키보드가 뜨면 안 됨
- 개발용 편의(코인 지급 등)는 막지 말 것
- 그림은 GPT 로 뽑는다(시트 한 장에 여러 그림, 마젠타 배경 → 잘라서 투명)
- 금지(LAST FLOOR 기준, 수익 모델 공통 성향): 가챠·에너지·한정 시간 상품·유료 파워, 돈이 능력치에 닿는 것
- PC 는 Windows + PowerShell. 한글 파일을 PowerShell 로 쓰면 깨진다
